# OpenMCP Cloud 联调文档（gateway -> service -> openmcp-backend）

> 适用范围：本次实现的 core 链路为 `cloud auth`、`cloud projects`（members/invites）与 `cloud spec-cases`。
> 订阅/管理员/计费等接口不在本次文档覆盖范围内。

## 前置条件

1. `openmcp-backend` 已启动，并监听：
   - 默认：`http://localhost:8000/api/v1`
2. 本机能访问后端 HTTP（本地网络连通）
3. `openmcp-cli` 已可执行（`openmcp-client/cli/bin/openmcp-cli.js`）

## 关键约定（很重要）

1. `cloud auth login/register/...` 的 token 会写入 `service` 的本地 token 文件（默认 `~/.openmcp/token.json`，可通过环境变量 `OPENMCP_TOKEN_PATH` 覆盖），因此**重启后仍可继续登录态**。
2. `gateway` 仍需要运行，因为所有 `cloud projects/spec-cases/...` 命令都会通过 `gateway -> service -> openmcp-backend` 转发；但登录态不再强依赖“同一个 gateway 会话期间”。
3. `service/src/cloud/http-client.ts` 会自动把 `OPENMCP_API_BASE_URL` 规范到 `/api/v1`：
   - 建议设置为：`OPENMCP_API_BASE_URL=http://localhost:8000`（不要手动加 `/api/v1`）

## 1. 启动 Gateway

> 如端口 8282 已被占用，请改用其它端口并在命令里同步 `-p` 或 `-g`。

```sh
node "E:\jinhui\openmcp-client\cli\bin\openmcp-cli.js" gateway start -p 8282
```

验证 gateway websocket：

```sh
node "E:\jinhui\openmcp-client\cli\bin\openmcp-cli.js" gateway status -p 8282
node "E:\jinhui\openmcp-client\cli\bin\openmcp-cli.js" cloud auth status -g ws://localhost:8282
```

预期输出：`loggedIn: false`（首次一般未登录）。

## 2. 注册与登录（拿到 user.id / token）

### 2.1 注册 user1（项目所有者）

```sh
node "E:\jinhui\openmcp-client\cli\bin\openmcp-cli.js" cloud auth register \
  --email user1@example.com -u user1 -p user1pass \
  -g ws://localhost:8282
```

### 2.2 登录 user1

```sh
node "E:\jinhui\openmcp-client\cli\bin\openmcp-cli.js" cloud auth login \
  -u user1 -p user1pass \
  -g ws://localhost:8282
```

从输出里记录：
- `user.id`（记为：`USER1_ID`）

### 2.3 OAuth 登录（自动保存 tokens 到本地）

> 该命令会启动一个本地回调页（nonce -> tokens），OAuth 完成后自动写入 `service` 的 token 文件，并落盘到默认 `~/.openmcp/token.json`（或 `OPENMCP_TOKEN_PATH`）。

```sh
node "E:\jinhui\openmcp-client\cli\bin\openmcp-cli.js" cloud auth oauth github \
  -g ws://localhost:8282 \
  --open
```

验证：

```sh
node "E:\jinhui\openmcp-client\cli\bin\openmcp-cli.js" cloud auth status -g ws://localhost:8282
```

### 2.4 Device Code 跨设备登录（推荐用于远程/多机器）

> `cloud auth device <channel>` 会调用后端生成 `device_code/user_code` 并打印：
> - `verification_uri` / `verification_uri_complete`
> - `user_code`
>
> 你可以在另一台机器/浏览器打开 `verification_uri_complete` 完成授权，然后回到终端继续等待轮询出 token（CLI 会自动保存到本地）。

```sh
node "E:\jinhui\openmcp-client\cli\bin\openmcp-cli.js" cloud auth device github \
  --open \
  -g ws://localhost:8282
```

验证登录态：

```sh
node "E:\jinhui\openmcp-client\cli\bin\openmcp-cli.js" cloud auth status -g ws://localhost:8282
```

## 4. 项目成员（members）

> 服务器端限制：`members` 相关写操作需要当前用户是项目 owner（由 token 决定）。
> 你需要保证当前登录用户是 `USER1_ID`（项目所有者）。

### 4.1 注册 user2（准备要加入的用户）

如果你还没有 user2：

```sh
node "E:\jinhui\openmcp-client\cli\bin\openmcp-cli.js" cloud auth register \
  --email user2@example.com -u user2 -p user2pass \
  -g ws://localhost:8282
```

登录一次 user2 来拿 `user.id`：

```sh
node "E:\jinhui\openmcp-client\cli\bin\openmcp-cli.js" cloud auth login \
  -u user2 -p user2pass \
  -g ws://localhost:8282
```

记录：
- `user.id`（记为：`USER2_ID`）

然后重新登录 user1（因为成员写操作需要 owner）：

```sh
node "E:\jinhui\openmcp-client\cli\bin\openmcp-cli.js" cloud auth login \
  -u user1 -p user1pass \
  -g ws://localhost:8282
```

### 4.2 列出项目成员

```sh
node "E:\jinhui\openmcp-client\cli\bin\openmcp-cli.js" cloud projects members list \
  --project-id PROJECT1_ID \
  -g ws://localhost:8282
```

### 4.3 添加成员（user2 -> writer）

```sh
node "E:\jinhui\openmcp-client\cli\bin\openmcp-cli.js" cloud projects members add \
  --project-id PROJECT1_ID \
  --user-id USER2_ID \
  --role writer \
  -g ws://localhost:8282
```

### 4.4 更新成员角色

（示例：把 USER2 角色从 writer 改成 owner；服务端允许 owner/禁止 owner 的修改场景以返回为准）

```sh
node "E:\jinhui\openmcp-client\cli\bin\openmcp-cli.js" cloud projects members update-role \
  --project-id PROJECT1_ID \
  --user-id USER2_ID \
  --role writer \
  -g ws://localhost:8282
```

### 4.5 移除成员

```sh
node "E:\jinhui\openmcp-client\cli\bin\openmcp-cli.js" cloud projects members remove \
  --project-id PROJECT1_ID \
  --user-id USER2_ID \
  -g ws://localhost:8282
```

```sh

  --code INVITE_CODE \
  --user-id USER2_ID \
  -g ws://localhost:8282
```

## 6. Spec Case（projects/:id/spec-cases）

> 服务器端会用 Authorization 的 token 用户校验项目访问权限。
> 所以创建/更新/删除 spec-cases 前要先登录一个有权限的用户（例如 USER1_ID 或 USER2_ID，取决于你要操作谁）。

### 6.1 创建一个根节点（folder）

```sh
node "E:\jinhui\openmcp-client\cli\bin\openmcp-cli.js" cloud spec-cases create \
  --project-id PROJECT1_ID \
  --node-type folder \
  --type prompt \
  --name "RootFolder" \
  -g ws://localhost:8282
```

记录返回：
- `msg.id`（可用于作为 parentId）

### 6.2 创建一个子节点（case）

```sh
node "E:\jinhui\openmcp-client\cli\bin\openmcp-cli.js" cloud spec-cases create \
  --project-id PROJECT1_ID \
  --node-type case \
  --type tool \
  --name "weather.get_current" \
  --parent-id <ROOT_NODE_ID> \
  --input "{\"city\":\"beijing\"}" \
  --output "{\"ok\":true}" \
  -g ws://localhost:8282
```

### 6.3 获取 spec-cases tree

```sh
node "E:\jinhui\openmcp-client\cli\bin\openmcp-cli.js" cloud spec-cases tree \
  --project-id PROJECT1_ID \
  -g ws://localhost:8282
```

### 6.4 获取单个 spec 节点

```sh
node "E:\jinhui\openmcp-client\cli\bin\openmcp-cli.js" cloud spec-cases get \
  --project-id PROJECT1_ID \
  --case-id <CASE_NODE_ID> \
  -g ws://localhost:8282
```

### 6.5 更新 spec 节点

```sh
node "E:\jinhui\openmcp-client\cli\bin\openmcp-cli.js" cloud spec-cases update \
  --project-id PROJECT1_ID \
  --case-id <CASE_NODE_ID> \
  --node-type case \
  --type tool \
  --name "weather.get_current-renamed" \
  --input "{\"city\":\"shanghai\"}" \
  --output "{\"ok\":true}" \
  -g ws://localhost:8282
```

### 6.6 删除 spec 节点

```sh
node "E:\jinhui\openmcp-client\cli\bin\openmcp-cli.js" cloud spec-cases delete \
  --project-id PROJECT1_ID \
  --case-id <CASE_NODE_ID> \
  -g ws://localhost:8282
```

## 排错建议（你遇到问题时直接对照）

1. 如果提示 `Command not found`：说明 service 侧 controller 命令名没注册到 `requestHandlerStorage`（通常是命令拼写不一致）。
2. 如果提示 token/auth 失败：
   - 确认你先执行了 `cloud auth login`，且没有中途切换到另一个账号但没再切回需要的 owner。
3. 如果提示后端连不上：
   - 确保后端运行地址正确，并设置 `OPENMCP_API_BASE_URL`（建议：`http://localhost:8000`）。
4. 如果 gateway 端 websocket 不通：
   - 先用 `gateway status` 确认端口 8282 可达。
